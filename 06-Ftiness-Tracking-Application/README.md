# 06 - Fitness Tracking Application Design
## Abstract

This project focuses on the analysis and design of a fitness tracking application that supports users in managing their health, exercise, nutrition, and progress goals. The application was designed to help users create profiles, set fitness goals, log workouts, track meals, monitor progress, and view visual summaries of their health data.

The project applied software analysis and object-oriented design principles to define the system’s structure and functionality. It included system analysis, data attributes and methods, UML use case diagrams, UML class diagrams, and user interface prototypes. The proposed technology stack used JavaFX for the interface, Java for application logic, and a local Data Access Object pattern for storing and retrieving user data such as activity logs, fitness goals, and nutrition records.

This project demonstrates understanding of application design, object-oriented programming concepts, UML modelling, UI planning, data modelling, authentication, CRUD operations, and progress visualisation. It is especially relevant for showing software engineering fundamentals alongside AI and data science projects.

## Problem Statement

Many users want to improve their health and fitness but struggle to track their goals, exercise routines, nutrition, and progress consistently. Without a structured application, users may rely on scattered notes, manual tracking, or multiple disconnected tools.

This project addresses the need for a simple fitness tracking application that allows users to manage health data, set goals, log activities, and visualise progress in one system.

## Objectives
- To design a fitness tracking application that supports user profiles, goal setting, exercise logging, nutrition tracking, and progress monitoring.
- To define the system’s data attributes and methods using object-oriented principles.
- To create UML use case and class diagrams for system structure and user interactions.
- To design a user interface prototype for key user functions.
- To propose a suitable technology stack using JavaFX, Java, and local data storage.
- To improve understanding of software analysis, design, and application architecture.

## Methodology
1. System Analysis
The project began by identifying the purpose of the fitness tracking application and the core user needs.
2. Feature Identification
Key features were defined, including user registration, login, profile management, exercise logging, nutrition tracking, goal setting, and progress visualisation.
3. Data Modelling
Data attributes and methods were listed for user profiles, exercise logs, nutrition tracking, and progress tracking.
4. UML Use Case Design
Use case diagrams were created to show interactions between users and the system.
5. UML Class Diagram Design
Class diagrams were designed to represent the system’s object-oriented structure.
6. User Interface Prototyping
Interface screens were planned for key user interactions such as login, profile management, tracking, and progress viewing.
7. Technology Stack Planning
JavaFX was proposed for the interface, Java for core functionality, and local DAO-based storage for user records.

## Limitations
The project focused mainly on analysis and design rather than full implementation.
The proposed storage system used local files, which may not scale well for many users.
Wearable device integration was mentioned conceptually but not implemented.
No real user testing was conducted.
Security design would need improvement for real-world deployment.
The UI prototype could be further refined using modern design tools.
