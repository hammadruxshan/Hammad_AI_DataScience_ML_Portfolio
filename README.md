# AI, Data Science and Software Engineering Portfolio

## Abstract

This portfolio presents a collection of academic and practical projects completed throughout my Bachelor of Computer Science degree, specialising in Artificial Intelligence with a minor in Data Science. The projects cover multiple areas of modern computing, including machine learning, data mining, computer vision, big data technologies, statistical modelling, software engineering, and AI-driven product design.

The purpose of this portfolio is to demonstrate my ability to work across the full data and AI project lifecycle: understanding a real-world problem, selecting appropriate datasets, preprocessing and analysing data, applying suitable models or technologies, evaluating results, and presenting insights clearly.

Through these projects, I aim to show both technical development and problem-solving ability, while continuing to build toward a career in applied AI, machine learning, data science, or software engineering.
